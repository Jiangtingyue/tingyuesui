# 花海水波场景（v8.9.8 全栈内置版）

花海已作为 JTYHome 同源模块内置，不依赖 CDN、远程纹理或第三方渲染服务。

## 后端

- `water_scene.py` 校验花海图片、样式与三个运行时文件，并提供短指纹和健康状态。
- `GET /api/water-scene/status` 返回最小健康信息。
- `GET /api/water-scene/bootstrap` 返回默认档位；前端使用同一路径的 `POST` 请求提交非持久化设备能力，协商 high / balanced / eco 档位。
- 能力信息只用于当前响应，不写数据库、日志或个人资料。

## 前端

- `water-refraction.runtime.js` 使用 WebGL 纹理折射与 CPU 高度场；纹理上传、uniform 查询和指针采样均有缓存或合帧。
- Pointer Events 同时支持鼠标悬停、按下涟漪、压感笔和多指触摸；高刷新率鼠标事件每帧合并，再按轨迹距离插值，避免断点和过密波纹。
- 页面隐藏时暂停动画，恢复时继续；设备档位控制 DPR、模拟尺寸、目标帧率和环境装饰。
- WebGL 不可用或上下文丢失时保留本地花海图片，并切换到可交互 CSS 水纹；上下文恢复后自动回到 WebGL。
- `hero-fx.runtime.js` 的花瓣与闪光在节能或减少动态效果档位下关闭，不影响用户主动制造的水纹。

打开水波后自动进入互动场景；从顶部选择晴天或雨天，或点击场景内“返回”，都会立即停止相关循环并回到主应用。
